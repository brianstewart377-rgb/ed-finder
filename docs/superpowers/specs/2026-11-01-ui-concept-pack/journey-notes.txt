ED:FINDER — revised UI/UX concepts, 1 November 2026

DESIGN
Elite Dangerous orange, glossy gunmetal, midnight navy and neon deep blue. Rounded panels/buttons, soft reflections, crisp text. Main tasks use tabs; occasional tools use closable, movable/dockable popouts.

JOURNEY
Finder: archetype selection and results first. Any uses Best Colony Potential; a selected archetype uses fit for that archetype.
Body filters: optional grouped sliders, with Reset/Cancel/Apply. Applied filter chips remain visible when closed.
Show on map: opens the selected system on demand. Closing preserves search, filters, selection and scroll position. Expand enables broader exploration.
Inspect: Overview/Bodies/Stations tabs, seven independent economy potentials, evidence explanations in a popout.
Plan: System layout/Build order tabs, facility preview popout, explicit Add to plan. Unknown slots remain unknown; separate Tier 2 and Tier 3 balances.
Review/export: a popout over the plan, unresolved information linked to the relevant body/build, explicit draft export without claiming build eligibility.

FINDER CONTROLS
Any plus: Paradise World; Mining Hub; Manufacturing Hub; Megacomplex; Research Hub; Stronghold; Population Capital; Flexible Multi-Role Colony.
Selected-mode minimum tiers are B/A/S in the reviewed repository contract.
18 body counts:
Planets (9): Earth-like, water worlds, ammonia worlds, terraformable, gas giants, high metal content, metal-rich, rocky, icy.
Stars (4): black holes, neutron stars, white dwarfs, other stars.
Features (5): landable, walkable, rings, biological signals, geological signals.
Count filters are not ranking weights. Future V3 ranking-weight dimensions are not yet defined and were not invented here. Production combinations must respect actual API capabilities.
