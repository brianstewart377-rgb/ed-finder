# ED-Finder documentation archive

This archive preserves decision chronology, implementation evidence, receipts,
and superseded plans. Archived material is historical evidence only. It never
overrides the current authority set in the [root README](../../README.md), never
answers “what next?”, and never authorizes production, deployment, database, or
application work.

Dates, stage labels, “current,” “production,” and “authorized” statements inside
an archived file describe the file's historical context. In particular,
references to Hetzner/V2, old runtime/cron/database state, and the Stage 26 R3F
production cutover are not statements about V3 production.

## Archive map

- [`stage-25/`](stage-25/) — completed Stage 25 roadmap, visual/evidence
  contracts, shell context, and bounded feature briefs.
- [`stage-26/`](stage-26/) — completed Stage 26 requirements, equal renderer
  bakeoff, R3F selection, implementation hand-offs, and V2-era cutover evidence.
- [`superpowers-map/`](superpowers-map/) — superseded map implementation plans
  and specifications, including R3F split, exploration layer, real-star
  streaming/LOD, glow/body thumbnails, and the August 16 narrow Babylon plan.
- Other `stage-*` files and archive subdirectories preserve earlier product,
  data, and operational history.

Stage 27A capability, readiness, and inheritance audits remain beside the
current spatial contracts because they are still useful evidence inputs. Their
status is explicitly audit/evidence; they are not roadmap or authorization
authority.
